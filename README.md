# IDRISOV COPYRIGHT GALLERY — Android source

Kotlin + Jetpack Compose. Local gallery, sorting, fullscreen zoom, image details, filtering unmarked images, manually declared ownership, Android-confirmed deletion. No internet permission and no uploads.

**IMPORTANT:** The app DOES NOT determine copyright, image ownership, license terms, or permission to reuse. Manual declaration is not verification. No reverse image search or license lookup is implemented.

## Build
Android Studio: open this folder, sync Gradle, Build > Build APK(s). Android SDK 35, JDK 17 and Gradle 8.9 required. GitHub Actions workflow is included for optional build. This source was not compiled in the current environment.
